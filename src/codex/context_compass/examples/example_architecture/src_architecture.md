# Example: src_architecture

This example demonstrates a compliant section structure for
`system_docs/src_architecture.md`.

Sections included
- Metadata
- Scope and Intent
- Unknowns Gate + Unknowns
- System context and boundaries
- C1 map entries with `verified_at`
- Diagrams and information sources

Use this as a structure reference, not as source-of-truth architecture.
